# Устройства как файлы и отображение файлов в память

Анимация на [Manim Community](https://github.com/ManimCommunity/manim/) по теме «доступ к устройствам через файловый интерфейс и file memory mapping». Команда: Иванов, Гусев (3211).

Ролик ведёт зрителя по двум маршрутам:

1. `/dev/ttyS0` → `open` → VFS и структуры ядра → дескриптор; `read` обращается к обработчику TTY, а принятые UART байты через serial-драйвер и буфер TTY попадают в буфер процесса.
2. Обычный файл → `mmap` → область виртуальной памяти → page fault → страница кэша → общий или личный доступ к данным.

Финал соединяет маршруты: **если драйвер поддерживает отображение**, память устройства можно предоставить процессу через `mmap`. Для наглядности показана условная модель `/dev/fb0`. Возможности и устройство памяти реального framebuffer зависят от драйвера.

Визуальный ориентир — [Core Dumped](https://www.youtube.com/@CoreDumpped): тёмный фон, простые схемы, постоянные цвета ролей и движение вызовов и данных. Графика ролика создаётся средствами Manim.

## Обсуждение с преподавателем

[docs/proposal.md](docs/proposal.md) содержит исследование темы, первичные источники, раскадровку и замечания преподавателя к первой части. По итогам обсуждения переработаны сцены про `/dev/ttyS0`, `open()` и `read()`. Часть про `mmap` пока остаётся предложением для следующего обсуждения.

Итоговый рендер 1080p/30 длится **116,63 с**, а первая часть для преподавателя — **около 66,3 с**. Это укладывается в диапазон задания 30–120 секунд; каждая содержательная сцена занимает 14–24 секунды. Подписи удерживаются на экране после появления, чтобы их можно было прочитать вместе со схемой. Короткий титр при отдельной сдаче объединён с первым фрагментом.

Исходники `animation/*.py` содержат около 1000 строк Python и укладываются в ориентир задания по объёму кода.

## Сцены

| Файл | Сцена | Содержание |
|---|---|---|
| `s0_title.py` | `TitleScene` | Название и основные сущности: устройство, файл, память |
| `s1_dev_files.py` | `DevFilesScene` | `/dev/ttyS0`, тип `c`, `4:64`, запись inode в VFS ядра |
| `s2_open.py` | `OpenScene` | `open` → VFS → inode → обработчики TTY → `struct file` → таблица дескрипторов; `fd` как индекс |
| `s3_read.py` | `ReadScene` | Жизненный цикл данных: запрос через `fd` и TTY, ответ UART → serial-драйвер → буфер TTY → `buf` процесса |
| `s4_mmap.py` | `MmapScene` | Обычный файл: VMA, первый page fault, кэш страниц и повтор доступа |
| `s5_shared.py` | `SharedScene` | `MAP_SHARED`, запись и `msync`; краткое сравнение с `MAP_PRIVATE` |
| `s6_framebuffer.py` | `FramebufferScene` | Условное отображение `/dev/fb0` и сравнительный итог |
| `full_video.py` | `FullVideo` | Все сцены в одном ролике |
| `full_video.py` | `TeacherPreview` | Титр и согласованная первая часть: `/dev`, `open()`, `read()` |

`style.py` задаёт палитру и типографику, `components.py` — повторно используемые карточки, ячейки, стрелки и значки, `base.py` — общие приёмы сцен (заголовки и подписи).

Цвета постоянны: синий — процесс и пользовательское пространство, фиолетовый — структуры ядра, бирюзовый — обработчики TTY и serial-драйвер, оранжевый — устройство, зелёный — данные, жёлтый — изменённые данные, красный — page fault.

## Установка

Нужен Python 3.11 или новее. Зависимость Manim зафиксирована в [requirements.txt](requirements.txt). Команды из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

На Linux/macOS вместо активации PowerShell: `source .venv/bin/activate`. Для Manim могут понадобиться системные библиотеки Cairo и Pango; см. [официальную инструкцию](https://docs.manim.community/en/stable/installation.html).

## Рендер

Команды выполняются **из каталога `animation/`** с активированным виртуальным окружением:

```powershell
cd animation
python -m manim -pql s2_open.py OpenScene       # быстрый просмотр одной сцены
python -m manim -qh --fps 30 full_video.py FullVideo  # весь ролик, 1080p/30
python -m manim -qh --fps 30 full_video.py TeacherPreview  # первая часть для преподавателя
```

Отдельные сцены можно отрендерить по одной, заменяя имя файла и класса по таблице выше. Manim записывает видео в `animation/media/videos/`. Перед сдачей стоит посмотреть готовый ролик целиком: проверить читаемость подписей, отсутствие наложений и фактическую длительность.

## Работа в репозитории

По условию задания преподавателя нужно подключить к репозиторию **при его создании**. Каждый участник оформляет свой вклад коммитами со своего личного аккаунта. Результат обсуждения с преподавателем и согласованные изменения сценария следует сохранять в `docs/proposal.md`; код сцен и документацию коммитить вместе с соответствующими изменениями.

Виртуальное окружение и файлы рендера исключены из репозитория через `.gitignore`.
